# Python Practice Projects

A collection of small validation and data-processing tools built while learning Python.

| Project | Description | Skills |
|---|---|---|
| [ipv4-validator](./ipv4-validator) | Validates IPv4 address strings | regex, pytest |
| [csv-cleaner](./csv-cleaner) | Reformats CSV name/house data | CSV |
| [api-price-checker](./api-price-checker) | Converts BTC amount to USD via live API | requests/API |
| [image-overlay-tool](./image-overlay-tool) | Overlays a PNG template onto a photo | Pillow |
| [date-normalizer](./date-normalizer) | Normalizes date strings to ISO format | regex |
